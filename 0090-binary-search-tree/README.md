# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. `std::unique_ptr<Node>` owns each subtree (freed automatically); `insert` takes the link by reference so it can replace an empty one.

## Run

    make && ./bst
