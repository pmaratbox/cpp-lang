# 0029 — Bitwise Operations

Compute bitwise AND, OR, and XOR on `6` and `3`, plus a left shift of `6` by one bit, printing `and: 2`, `or: 7`, `xor: 5`, and `shift: 12`. C++ shares C's `&`, `|`, `^`, and `<<` operators on integers; `6 << 1` doubles to 12. The parentheses around each expression are needed because `<<` is also the stream-insertion operator, which binds tighter here.

## Run

    make && ./bitwise
