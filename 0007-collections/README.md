# 0007 — Collections

Build a vector of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. `std::vector<int>` is the standard growable array;
`.size()`, `.front()`, and `.back()` read its length and ends.
`std::array<int, 5>` is the fixed-size, stack-allocated alternative when the
length is known at compile time.

## Run

    make && ./collections
