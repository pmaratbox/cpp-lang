# 0004 — Conditionals

Compare `n` against 10 and print whether it's less, equal, or greater. Same
syntax as C. C++17 added an init-statement form
(`if (auto x = expr; cond) { … }`) — not used here but worth knowing. Edit
`n` to `10` or `15` to exercise the other branches.

## Run

    make && ./conditionals
