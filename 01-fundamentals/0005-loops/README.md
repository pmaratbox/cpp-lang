# 0005 — Loops

Print 1..5 with the classic three-part `for` loop. Same shape as C; the
`++i` (pre-increment) form is conventional in C++ to avoid creating a
throwaway temporary when the operand is a user-defined iterator. C++11
added the range-based form (`for (auto x : container)`) for iterating
containers.

## Run

    make && ./loops
