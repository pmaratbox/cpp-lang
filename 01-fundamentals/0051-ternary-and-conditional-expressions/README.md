# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. C++ inherits C's `?:` conditional operator, which yields one of two values inline. Unlike C, its result can be an lvalue, so it may even appear on the left of an assignment.

## Run

    make && ./ternary
