# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). C++'s `/` between two `int`s truncates toward zero, same
as C. Use `static_cast<double>(a) / b` for the fractional quotient. `<<`
handles each operand's default formatting, no `printf` format string needed.

## Run

    make && ./arithmetic
