# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. `std::map` is an ordered tree map; a range-`for` with structured bindings `[key, value]` visits each pair to sum the values. `std::unordered_map` is the hash-based alternative.

## Run

    make && ./maps
